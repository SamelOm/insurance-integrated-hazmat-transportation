# Scripts

The scripts are standalone experiment programs retained from the thesis workflow. Run them from the repository root; their data paths are resolved relative to the script location.

Start with `solve_case_study.py`. The factorial, new-path, rerouting, cost, and regret scripts solve many additional models and should be run only after the core case study reproduces successfully.

Scientific differences between the thesis and code are tracked in [`docs/implementation_audit.md`](../docs/implementation_audit.md).
